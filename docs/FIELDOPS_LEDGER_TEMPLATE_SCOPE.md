# FieldOps Ledger Template Scope

## 1. Project Identity

FieldOps Ledger is a portfolio demo template adapted from FieldLedger.

It is not a client-ready starter product yet.

Public-facing description:

FieldOps Ledger is a customizable field operations ledger for mobile workers, contractors, technicians, inspectors, and service teams.

## 2. Main Proof Goal

FieldOps Ledger should prove that a real offline workflow app can be adapted into practical tools for different kinds of field and service workers.

It should not try to prove that this is a full SaaS platform.

## 3. Source Relationship

FieldLedger remains the original private workflow app.

FieldOps Ledger is the copied, sanitized, generalized portfolio version.

Rules:

- Keep the original FieldLedger repo untouched.
- Give this copied project its own repo identity.
- Do not include private configs.
- Do not include real import tokens.
- Do not include real Google Sheet URLs.
- Do not include real Apps Script deployment IDs.
- Do not include private calendar data.

## 4. Feature Freeze Boundary

The first conversion phase is identity and wording only.

Keep:

- jobs and work records
- expenses
- summaries
- backup and import
- CSV export
- printable reports
- local/offline behavior
- PWA behavior
- Google Sheets/export concept
- optional Google Calendar proof concept

Do not add yet:

- login
- backend
- cloud sync
- roles
- permissions
- payments
- admin dashboard
- multi-user accounts
- settings engine
- major redesign
- new Google integration logic

## 6. Proof Package

The final portfolio proof should include:

- live app demo
- README or case study
- sanitized screenshots
- app record-entry screenshot
- export/report screenshot
- Google Sheets proof screenshot
- Google Calendar proof screenshot if applicable
- what this proves section
- what this does not include yet section

## 7. Screenshot Privacy Boundary

Screenshots must use fake demo data only.

Do not show:

- real customer names
- real company names
- real worker names
- real addresses
- real pay data
- real job IDs
- real Sheet URLs
- Apps Script deployment IDs
- import tokens
- private calendar events

## 8. Portfolio Positioning

FieldOps Ledger should sit beside the smaller PWA samples as a larger case-study app.

Suggested portfolio label:

FieldOps Ledger — deeper offline-first field operations template adapted from a real workflow app.
